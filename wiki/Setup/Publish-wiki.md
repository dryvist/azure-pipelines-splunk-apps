# Publish the wiki

One time. Done at project setup; you should not need this again.

Publish the repository's `wiki/` folder as the project wiki.

1. Open **Overview → Wiki → Publish code as wiki**.
2. Select repository `azure-pipelines-splunk-apps`, branch `main`, and folder `/wiki`.
3. Publish the code as the wiki.

Verify:

1. Confirm the repository pages appear in the Azure DevOps project wiki.
2. Confirm the wiki starts at [Home](/Home).

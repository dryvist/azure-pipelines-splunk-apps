# Reading logs

[Home](/Home) > [Reference](/Reference) > Reading logs

[[_TOC_]]

Use the job log to find the first failed action and follow-up report.

- Blue `##[command]` lines show commands run by the script.
- Green section headings identify actions.
- Comparison logs use one section banner per file with its status.
- Yellow warnings include non-failing notices such as `future_failure`.
- The AppInspect JSON appears in the report step; its HTML link points to the
  artifact for that run.
- Disable **Enable system diagnostics** on the Run panel when its output is
  not needed.

See [Artifacts](/Reference/Artifacts) for artifact names and contents.

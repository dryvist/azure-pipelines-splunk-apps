# Azure DevOps setup

Use this checklist to open the setup procedures; read
[the prerequisites](wiki/Getting-started.md) before beginning.

## Checklist

| Step | Purpose |
| --- | --- |
| [Step 1](wiki/Getting-started/Feed.md) | Create the package feed and grant publish access. |
| [Step 2](wiki/Getting-started/Variable-groups.md) | Create the five variable groups. |
| [Step 3](wiki/Getting-started/Environments-and-ACS.md) | Create the two deployment environments. |
| [Step 4](wiki/Getting-started/Environments-and-ACS.md) | Create ACS tokens and grant export access. |
| [Step 5](wiki/Getting-started/App-repository.md) | Create an app repository and add its pipeline files. |
| [Step 6](wiki/Getting-started/App-repository.md) | Grant the Build Service app repository permissions. |
| [Step 7](wiki/Getting-started/App-pipeline.md) | Create a pipeline from the existing YAML file. |
| [Step 8](wiki/Getting-started/App-pipeline.md) | Permit the pipeline to use its resources. |
| [Step 9](wiki/Getting-started/App-pipeline.md) | Require pipeline validation for pull requests to `main`. |
| [Step 10](wiki/Getting-started/App-pipeline.md) | Check the first pull request run and its artifacts. |
| [Step 11](wiki/Getting-started/Release.md) | Check the first release after merging. |
| [Step 12](wiki/Getting-started/Manual-deploy.md) | Create the manual app deployment pipeline. |
| [Step 13](wiki/Getting-started/Publish-wiki.md) | Publish the repository wiki. |
| [Step 14](wiki/Getting-started/Compare.md) | Create the environment compare pipeline. |
| [Step 15](wiki/Getting-started/Restart.md) | Create the stack restart pipeline. |
